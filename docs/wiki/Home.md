# Material Roblox

**A Material Design 3 desktop explorer for the Roblox platform APIs.**
Browse users, friends, groups, games, marketplace, and inventories through a
fast, local, privacy-respecting Windows app — no account required for public
data, and nothing phoning home.

## What it does

- **Roblox explorer** — user lookup with avatar renders, friends and followers
  lists with bulk export, group info with roles and public shout walls, game
  and universe details with stats and badges, catalog search with filters,
  public inventories by asset type, two-user compare, and economy + presence
  surfaces behind an opt-in session stored in the OS credential vault.
- **Interface** — a dockable browser-style tab strip (pinning, groups,
  discovery searches, bulk close), a `Ctrl+Shift+F` command palette that
  teleports to any element, a full regex builder anchored beside every search
  field, non-blocking notifications, bulk actions on every list, exports in
  JSON/JSONL/YAML/TOML/XML/CSV/TSV/Markdown/HTML/SQL/ZIP, Git-backed local
  history, and an in-app changelog viewer.
- **Appearance** — full Material Design 3 conformance, light/dark/system
  themes, density control, an infinite colour picker with a bidirectional
  colour-space translator and animated-rainbow option, word-processor-depth
  typography editing, per-element *Edit appearance…*, and app-logo presets
  plus bounded local custom-logo conversion.
- **Safety & delight** — destructive-action super confirmation (two keys plus
  a slider), per-element toy locks with self-service recovery, an unlock
  ladder that clears waiting without ever clearing credentials, a built-in
  RFC 6238 authenticator with in-process QR pairing, English / playful
  Cantonese / bilingual modes with per-language funny-level sliders, School
  mode, an opt-in narrator, five ADHD accommodations, and the dim sum
  surprise.

site 4,558 · docs 3,040 · scripts 1,770 · workflows 330. The README carries
